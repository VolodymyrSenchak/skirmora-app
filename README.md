# pocket-legions-app

Web client for Pocket Legions (Angular 22, phone first, installable as a PWA). There are two ways to play: online in rooms through [pocket-legions-api](../pocket-legions-api/README.md), or hot-seat, passing one device around with no network.

**Status:** Phases 0–5 done (hot-seat and online play); Phase 6 (ship) is next — see the plan.

- Plan: [docs/implementation/pocket-legions.app.implementation-plan.md](docs/implementation/pocket-legions.app.implementation-plan.md)
- Game design: [../design/pocket-legions.game-design.md](../design/pocket-legions.game-design.md)
- Prototype art and battle demo: [../design/art](../design/art/index.html)

## Commands

```
npm start              # dev server on http://localhost:4200 (/dev shows the atlases and maps)
npm run test:run       # Vitest
npm run build          # production build (checks the engine copy first)
npm run sync:engine    # copy the pure engine from ../pocket-legions-api (add -- --check to verify)
npm run sync:art       # copy the sprite atlases from ../design/art/atlas
npm run api:memory     # pocket-legions-api on :8080 in memory (no Supabase), CORS for :4200
```

`src/app/engine/` is generated by `sync:engine` from the API repo. Never edit it here: rule changes belong in pocket-legions-api.
